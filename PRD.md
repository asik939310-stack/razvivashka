# PRD: «Учим буквы вместе»

## 1. Обзор

**Название проекта:** Учим буквы вместе
**Тип продукта:** Веб-приложение (single-page HTML/CSS/JS) для раннего обучения детей
**Платформа:** Браузер (desktop и mobile, адаптивная вёрстка)
**Язык интерфейса:** Русский, с элементами казахского языка

### 1.1 Описание

Интерактивное обучающее приложение для детей дошкольного и младшего школьного возраста. Помогает изучать русский алфавит, слоги, слова и цифры, а также базовую казахскую лексику (специальные буквы әліпби, части тела, цвета, животные, действия). Приложение использует голосовую озвучку (Web Speech API) и систему звёздочек для мотивации.

### 1.2 Целевая аудитория

- Дети 3–7 лет, изучающие русский алфавит и счёт
- Дети из русско-казахских семей, изучающие базовую казахскую лексику параллельно с русской
- Родители/воспитатели, ищущие простой инструмент для занятий без регистрации и рекламы

### 1.3 Проблема, которую решает продукт

Родителям нужен простой, безопасный, бесплатный инструмент без рекламы и отвлекающих элементов, который можно открыть в любой момент для короткого занятия с ребёнком — без установки приложений и создания аккаунтов.

## 2. Цели и метрики успеха

| Цель | Метрика |
|---|---|
| Ребёнок может заниматься самостоятельно | Минимум инструкций текстом, крупные кнопки, голосовая озвучка |
| Занятие не вызывает фрустрации | Нет ограничений по времени, нет «проигрыша», можно всегда вернуться назад |
| Мотивация продолжать | Счётчик звёздочек, прогресс-точки без давления |
| Доступность на любом устройстве | Адаптивная вёрстка для мобильных и десктопа |

## 3. Функциональные разделы (модули)

### 3.1 Домашний экран
Приветственный экран с совой-талисманом и кнопками быстрого перехода во все разделы.

### 3.2 Буквы
- 12 букв русского алфавита с примером слова и эмодзи-иллюстрацией
- Подсветка изучаемой буквы внутри слова
- Озвучка буквы и слова
- Навигация «Назад / Слушать / Дальше»

### 3.3 Слоги
- 12 пар согласная+гласная (слияние слогов)
- Визуальное отображение раздельных букв, кнопка «Соединить» показывает слитный слог
- Озвучка по слогам и слитно

### 3.4 Слова
- 10 слов с подбором картинки (эмодзи) из 3 вариантов
- Два режима: «Слово написано» (текст виден) и «Только голосом» (только аудирование — режим для проверки восприятия на слух)
- Обратная связь при правильном/неправильном выборе, подсказка после ошибки

### 3.5 Цифры
- Числа от 0 до 20
- Визуализация количества через сетку точек (по 5 в ряд)
- Озвучка числа

### 3.6 Тематические блоки (казахский язык)
Единый шаблон экрана для 5 тем:
- **Әліпби** — особые буквы казахского алфавита (Ә, Ғ, Қ, Ң, Ө, Ұ, Ү, Һ, І) с примером слова и переводом
- **Тело** — части тела (11 слов)
- **Цвета** — 9 цветов
- **Животные** — 9 домашних животных
- **Действия** — 12 фраз о повседневных действиях ребёнка

Каждая карточка: эмодзи, слово на казахском, перевод на русском, озвучка с корректным `lang` (kk-KZ / ru-RU).

## 4. Сквозная функциональность

- **Озвучка (Web Speech API):** переключатель звука вкл/выкл в шапке; при переходе между экранами текущая озвучка прерывается
- **Звёздочки:** начисляются за переход «Дальше» в каждом разделе; накопительный счётчик в шапке (в рамках одной сессии, без сохранения)
- **Прогресс-точки:** ненавязчивый индикатор текущей позиции в списке (пройдено / текущий / осталось), без чисел и таймеров
- **Навигация:** боковое меню (десктоп) / верхняя строка кнопок (мобильный), всегда видно все разделы

## 5. Нефункциональные требования

| Требование | Реализация |
|---|---|
| Без сервера и бэкенда | Полностью статичный HTML/CSS/JS, работает офлайн после загрузки страницы |
| Без сбора персональных данных | Нет форм, аналитики, cookies |
| Адаптивность | Медиа-запрос для экранов до 640px: меню становится горизонтальным, уменьшаются шрифты |
| Доступность | Крупные кнопки (мин. высота 52px), высокий контраст, аудио-дублирование текста |
| Производительность | Один HTML-файл, без внешних зависимостей и запросов |

## 6. Технический стек

- HTML5 / CSS3 (кастомные CSS-переменные для темизации)
- Vanilla JavaScript (без фреймворков)
- Web Speech API (`SpeechSynthesisUtterance`) для озвучки на русском и казахском

## 7. Текущие ограничения

- Прогресс и звёздочки не сохраняются между сессиями (сбрасываются при перезагрузке страницы)
- Озвучка казахского языка зависит от наличия голоса `kk-KZ` в браузере/ОС пользователя; при отсутствии голос может звучать с акцентом или не воспроизводиться
- Ограниченный словарный набор (фиксированные списки букв/слов/тем, не редактируется через интерфейс)
- Нет системы уровней сложности или адаптации под возраст ребёнка

## 8. Возможные направления развития (не в текущей версии)

- Сохранение прогресса и звёздочек (localStorage или аккаунт)
- Расширение словарных наборов и добавление новых тем
- Мини-игры (сопоставление, память, диктант букв)
- Настройка скорости и голоса озвучки
- Многоуровневая сложность по возрасту
- Экран для родителей со статистикой занятий

## 9. Из объёма (Out of Scope)

- Регистрация пользователей и профили нескольких детей
- Монетизация, реклама, платный контент
- Серверная синхронизация между устройствами
